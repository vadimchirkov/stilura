## Description (≤260, fits both PH limits)

```
Open-source Markdown editor that runs on your machine. Select a sentence, press ⌘K, take one of the rewrites or keep yours. Type / to write a line in place. Your file doesn't change until you press Tab. Runs on your ChatGPT or Claude plan, or an API key.
```

## Maker comment

```
Hi, I'm Vadim. I built Stilura.

You select a passage, press ⌘K, say what you want and ↑/↓ through the
versions. Tab keeps one. A / request at the end of a line writes right there;
R asks again. Stop typing for a second and it offers a gray continuation,
which you're free to ignore.

Your draft doesn't change until you accept something. Voice rules live in a
style.md next to it, and the default one is a list of common chatbot tells.

It signs in with ChatGPT Plus/Pro or uses Claude Code on Pro/Max. An API key
works too. MIT. It's not a detector, and it won't write the post for you.

What would you put in your style.md first?
```
